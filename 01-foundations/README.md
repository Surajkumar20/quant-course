# Phase 1: Foundations (weeks 5–11)

Three projects that turn probability, linear algebra and statistics from material you've read into tools you use.
Every later phase depends on these.

| Project | Lang | Weeks | OCW backbone |
|---|---|---|---|
| [p01 Monte Carlo probability lab](p01-monte-carlo-probability/) | Python | 5–6 | 18.600, 6.0002 |
| [p02 Matrix library](p02-matrix-library/) | C++ | 7–8 | 18.06SC, 6.S096 |
| [p03 Statistics toolkit](p03-statistics-toolkit/) | Python | 9–11 | 18.650 |

**Exit criteria:** you can derive a closed form, simulate it, and say whether the two agree within the noise **with a confidence interval**. And you can write numerical C++ that is correct before it is fast.
